# Sistema de Gestión Médica — EsSalud Matellini

Proyecto académico del curso **Lenguaje de Programación — UAIN1288P**, de la Universidad Privada del Norte.

El sistema es un prototipo en Python para organizar pacientes, citas médicas y reportes, tomando como contexto el establecimiento de EsSalud de Matellini, Chorrillos. No es un sistema oficial de EsSalud ni está preparado para uso clínico real.

## Objetivo

Aplicar programación orientada a objetos, estructurada y funcional en un sistema que permita organizar información y operaciones básicas de gestión médica.

## Funcionalidades

- Registro de pacientes y validación de datos.
- Consulta y actualización de información de pacientes.
- Búsqueda de pacientes por nombre.
- Asignación de historias clínicas.
- Programación y cancelación de citas médicas.
- Gestión del estado de las citas.
- Generación de reportes de pacientes y citas.
- Protección y verificación de contraseñas mediante hashes.

## Tecnologías

- Python 3.
- Git y GitHub para el control de versiones.
- Visual Studio Code como entorno de desarrollo.
- `unittest` para pruebas automatizadas.
- Módulos de Python como `datetime`, `hashlib`, `secrets` y `hmac`.
